Ask Alexa+ which commit broke your build.

DevPulse is an MCP server for Alexa+. It reads your GitHub Actions runs, pull requests and commits, then answers in a few spoken sentences. It is written in Python, MIT licensed, and you host it yourself.

Question

What happened in the repo this week?

Tool call sent to the server 
get_repo_activity {"repo": "microsoft/vscode", "days": 7}
Answer

The VS Code repository saw high activity this week with thirty commits and twenty-four new issues opened, but only one issue was closed. Five pull requests were submitted. Recent work focused on modern UI updates, fixing sandbox write confirmations, and optimizing Azure Pipeline test jobs.

Tools

Tool Question Reads
get_ci_status What is the CI status? Recent GitHub Actions runs
get_test_results What failed in the last test run? Jobs and steps of the latest run
get_pr_summary Which pull requests are open? Open pull requests and their reviews
get_repo_activity What happened this week? Commits and issues over a number of days
trace_breakage Who broke main? The last passing run, the first failing run, and the commits and files between them

trace_breakage hands that evidence to a language model, which names the commit most likely responsible. It reasons from commit messages and file names, so treat the answer as a lead to check.

How it works

  1. Alexa+ sends a JSON-RPC message to the /mcp endpoint, using MCP 2025-11-25 over Streamable HTTP.
  2. The server calls the GitHub REST API with the token you provide.
  3. A language model (Gemini in the current version) shortens the result into spoken sentences. If the model fails, the server returns a few lines of the plain GitHub data.

Setup

You need Python 3.12, a GitHub token with read access to the repositories you ask about, and a Gemini API key.

Windows (PowerShell) 
git clone REPLACE_REPO_URL devpulse
cd devpulse\server
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy ..\.env.example ..\.env
python main.py
macOS and Linux 
git clone REPLACE_REPO_URL devpulse
cd devpulse/server
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp ../.env.example ../.env
python main.py

Put GITHUB_TOKEN, GEMINI_API_KEY and GEMINI_MODEL in the .env file, then open http://localhost:8000/simulator. To connect Alexa+, serve the /mcp endpoint over HTTPS.
