Privacy policy

Last updated 19 October 2026.

This website

The site is static. It sets no cookies, runs no analytics and loads no third-party scripts, fonts or images. Our host may keep standard server logs (IP address, browser and requested page) for security and operations.

The DevPulse software

DevPulse is self-hosted. Whoever runs a server is responsible for it, and the project authors receive no data from it.

To answer a question, the server reads data from GitHub using the token its operator provides: workflow run names, commit messages, author names, pull request titles and file names. That text is sent to the Gemini API from Google to produce a short spoken summary. Depending on the plan of the API key, Google may retain it or use it to improve its products, so check Google's terms for your plan.

The server keeps session identifiers in memory only, has no database, and logs request activity, including repository names, to its own console. Stopping the server clears the sessions.

Alexa+

If you connect DevPulse to Alexa+, Amazon handles your voice requests under its own terms. DevPulse receives only the tool call and its arguments, such as a repository name.

Your choices

Use a token with read-only access, rotate it whenever you like, and stop the server to stop all processing.
